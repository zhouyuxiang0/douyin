# 发布后归档

归档范围由当前项目规范和用户本次要求决定。发布授权不自动包含删除授权；已经确认的项目归档约定继续有效，不重复索要确认。

1. 先读取已有发布凭据，确认准确作品ID与 `published` 状态。项目约定发布成功后不补查时，直接沿用该成功凭据；仅在结果未知、失败或用户要求时运行 `dy publish-verify`。审核中、结果未知或校验失败时保留本地视频。核验凭据不是对公开播放/移动端画质的替代。
2. 按项目约定保留题目、核心知识点、日期、作品链接与简短发布凭据；迁移可复用知识，修正对本期文件的有效依赖。
3. 清理前核对精确路径、软链接/挂载、Git跟踪、打开的文件、相关进程与自动化；区分本期专属文件和共享工具、模型、参考人声、字体、音乐、品牌素材。
4. 仅删除明确获准的本地范围。不得删除线上作品、全局浏览器登录状态或共享资源；不将视频归档解释为聊天归档。用户要求保留成片/工程或另有保留约定时遵从。
5. 独立验证目标已移除、共享资源完整，记录实际空间变化；目录大小不等于实际释放空间。将凭据/截图置于待删目录以外，按项目保留约定保存，不额外留完整备份。

该 skill 提供发布凭据和归档操作流程，不提供一个隐式删除任意项目目录的发布开关。
